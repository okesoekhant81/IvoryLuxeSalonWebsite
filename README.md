# Ivory Luxe Salon

Marketing website for Ivory Luxe Salon (Al Rigga, Dubai), built with Next.js and Tailwind CSS from the project's Figma design.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it locally.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- `next/font` for Playfair Display + Inter
- `next/image` for optimized, responsive images

## Structure

- `src/components/` – page sections (Hero, About, Services, Experience, Testimonials, Visit) and layout chrome (Header, Footer, MobileNav)
- `public/images/` – salon photography exported from the Figma design, compressed for the web

## Deploy

Push to `main` (or connect the repo) on [Vercel](https://vercel.com/new) — no extra configuration is required.
